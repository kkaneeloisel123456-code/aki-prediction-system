## 键盘路径

实测路径：

1. 登录页初始焦点在账号输入框；输入 `pilotdoc`，`Tab` 到密码，输入密码；再 `Tab` 经“记住登录状态 → 忘记密码”到“登录”按钮。
2. 在“登录”按钮按 Enter 后进入工作台，标题“未发布评估”，侧栏用户“周明远”。
3. `Tab` 到“患者档案”，Enter 进入患者页；标题“患者档案”。
4. 继续 `Tab` 到“姓名或病历号”搜索框，输入“陈”，列表返回“共 1 条”。

结论：键盘焦点链完整，可从登录走到患者搜索；控件顺序与可见焦点符合预期。
